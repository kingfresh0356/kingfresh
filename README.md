# KingFresh Trading Website

A responsive, animated static website for KingFresh Trading, built for fruits and vegetables export.

## Files

- `index.html` — main website page
- `styles.css` — responsive styles and animations
- `script.js` — scroll animation support

## Preview

Open `index.html` in your browser to see the website.

## Response

To view the website response, open `index.html` in any browser. Use the contact form or the email listed on the page to request a quote or follow-up response from your exporter team.
